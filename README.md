# シェード（KiKi ボイスコマンドのボタン）

**https://takatronix.github.io/kiki/**

音声で操作する電動ルーフシェード（KiKi ボイスコントローラー）向けのボタンです。
ボタンを押すと、端末のスピーカーから「Hello KiKi」→ 少し待つ → 英語のコマンド（例: "Open Shade"）を順に流します。
英語で話さなくても、日本語のボタンを押すだけでシェードの開閉や照明の色を変えられます。

## 使い方
1. 車のブラウザ（テスラなど）かスマホで上の URL を開きます。
2. 「開く」「閉じる」「止める」や色のボタンを押します。1 回の音声は約 4 秒です。
3. 反応しないときは、メディアの音量を上げて、スピーカーをシェードに近づけてください。

- 一度開くと、次からは電波がなくても使えます。スマホではホーム画面に追加できます。
- ログイン、Cookie、アクセス解析は使っていません。

## ボタン
開く／閉じる／止める、照明オン／オフ、明るく／暗く、色（赤 緑 青 白 紫 シアン 黄 オレンジ ピンク）、
動き（レインボー 流れる 呼吸 グラデーション マジック スポーツ オート）。

## 声
音声は [Kokoro-82M](https://huggingface.co/hexgrad/Kokoro-82M)（Apache License 2.0）の内蔵ボイス `af_heart` で作りました。
実在の人の声をまねたもの（ボイスクローン）ではありません。Apache 2.0 なので、作った音声を配布できます。
