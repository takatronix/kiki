# シェード（KiKi ボイスコマンドのボタン）

**https://takatronix.github.io/kiki/**

音声で操作する電動ルーフシェード（KiKi ボイスコントローラー）向けのボタンです。
ボタンを押すと、端末のスピーカーから「Hello KiKi」→ 少し待つ → 英語のコマンド（例: "Open Shade"）を順に流します。
英語で話さなくても、日本語のボタンを押すだけでシェードの開閉や照明の色を変えられます。

## 使い方
1. 車のブラウザ（テスラなど）かスマホで上の URL を開きます。
2. 「開く」「閉じる」「止める」や色のボタンを押します。1 回の音声は約 4 秒です。
3. 反応しないときは、メディアの音量を上げて、スピーカーをシェードに近づけてください。

- 一度開くと、次からは電波がなくても使えます。スマホではホーム画面に追加できます。
- ログイン、Cookie、アクセス解析は使っていません。

## ボタン
説明書の音声コマンドを全部（41 個）入れています。どのボタンにも、流れる英語を小さく書いてあるので、自分で言うこともできます。
- シェード: 開く／閉じる／止める、音量を上げる／下げる
- 照明: 点灯／消灯、明るく／暗く、明るさ 1〜10、最小／最大
- 色: 赤 緑 青 白 紫 シアン 黄 オレンジ ピンク
- 動き: レインボー 流れる 呼吸 グラデーション マジック スポーツ オート
- 対応機種のみ: 赤と青／赤と緑／青と緑のグラデーション、水色の流れ

上の車の絵は、最後に最後まで流したコマンドからの目安です（シェードからの返事はありません）。

## 声
音声は [Kokoro-82M](https://huggingface.co/hexgrad/Kokoro-82M)（Apache License 2.0）の内蔵ボイス `af_heart` で作りました。
実在の人の声をまねたもの（ボイスクローン）ではありません。Apache 2.0 なので、作った音声を配布できます。

## 注意
- **非公式のツールです。** EVNOVA やシェードのメーカーとは関係ありません。
- 停車中に、シェードの動く範囲に何もないことを確かめてから使ってください。
- 使ったことで起きた問題について、作者は責任を負いません。

## つくり
- `index.html` `style.css` `app.js` と `clips/`（`clips/commands.json` に ID と英語）。ビルドは要りません。
- 音声を足すとき: `clips/commands.json` に書いて `tools/make_clips.py` を実行（まだない ID だけ作ります）。`sw.js` の一覧と CACHE の番号も更新します。
- 車の Web（tesla-pi4 の /shade）はこのリポジトリから `web/shade_sync.py` でコピーして作ります。直すのはこちらだけです。
